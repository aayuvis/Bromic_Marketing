# Tungsten Select — CAD (STEP)

Drop the Tungsten Smart-Heat® Electric Series II Select STEP files here (one per part or one assembly), plus:
- fascia variants (Diamond, oval, triangle) if separate,
- finish references (black, white, graphite),
- the Bromic logo as vector artwork (SVG or PDF),
- a photo of the elements lit (for glow colour).

Used to render studio shots and to composite the real product into Bromic library photographs.
